CREATIVE CLIQUE REAL ESTATE — BOOTSTRAP WEBSITE

Files:
- index.html: Main responsive website page.
- assets/: Folder reserved for local images, stylesheets, and scripts as the site grows.

HOW TO OPEN
1. Extract the ZIP folder.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.

NOTES
- The page uses Bootstrap 5.3.3 and Bootstrap Icons from public CDNs, so an internet connection is needed for those resources.
- The sample property cards and contact details are placeholders. Replace them with real, verified listings and your business contact information before publishing.
- The contact form currently contains YOUR_EMAIL@example.com. Replace that placeholder in index.html with your business email. The form uses the visitor's email app; it is not connected to a server-side form service.
- Property search filters the sample cards on the page; it is not connected to a live property database.
